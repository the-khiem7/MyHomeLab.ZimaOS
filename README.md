# MyHomeLab ZimaOS

MyHomeLab ZimaOS is a bilingual English and Vietnamese knowledge base for
setting up and operating a ZimaOS homelab. It documents first steps, secure
SSH access patterns, and public-safe operational notes for the self-hosted
applications recorded in the original homelab repository.

The content is maintained by The Khiem and published through GitHub Pages.
It intentionally omits deployment credentials, private endpoints, and local
Compose overrides.
